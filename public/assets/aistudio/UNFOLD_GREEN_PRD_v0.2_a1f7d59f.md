## 1. Project Overview

### 1.1 Purpose

UNFOLD GREEN의 브랜드 철학과 정원 디자인 프로젝트를 소개하고, 잠재 고객
및 협업 파트너가 브랜드의 관점과 작업 방식을 이해할 수 있는 공식
홈페이지를 구축한다.

홈페이지는 단순한 작업 실적 나열형 포트폴리오가 아니라, 정원 디자인
스튜디오의 관점과 감각이 드러나는 브랜드 중심의 웹사이트를 지향한다.

### 1.2 Brand

-   **Brand name:** UNFOLD GREEN
-   **Business type:** Garden Design Studio
-   **Professional title:** Garden Designer
-   **Tagline:** Designing spaces through plants and nature.
-   **Core services:** Garden Design / Garden Construction / Garden Care

### 1.3 Brand philosophy

UNFOLD GREEN은 식물을 공간의 장식 요소로만 보지 않는다. 식물은 완성된
공간에 생명력과 새로운 분위기를 더하고, 공간을 새롭게 경험하게 만드는
요소다.

장소의 특성과 공간 구조, 식물의 관계를 읽고 식재의 배치와 밀도, 여백,
빛과 그림자를 통해 자연스럽게 시선이 머물고 사람이 편안하게 머무는
정원을 디자인한다.

정원의 계획부터 설계, 시공, 유지관리까지 하나의 흐름으로 연결한다.

**Core keywords** - 머무름 (Stay) - 정제된 자연스러움 (Refined
Naturalness) - 시간의 흐름 (Flow of Time)

### 1.4 Target audiences

1.  정원 설계·시공·관리 의뢰 고객
    -   단독주택 및 개인 정원 소유자
    -   작은 정원을 원하는 상업공간 운영자
    -   테라스, 옥상, 실내 등 소규모 정원 조성 희망자
2.  전문 방문자 및 협업 파트너
    -   조경·건축·인테리어 회사
    -   공간 디자인 및 정원 분야 전문가
    -   관련 분야 협업 파트너

### 1.5 Website objectives

-   브랜드의 디자인 철학과 전문성을 전달한다.
-   주요 프로젝트를 시각적으로 완성도 있게 소개한다.
-   개인의 경력과 경험을 신뢰도 있게 보여준다.
-   정원 설계 및 시공 문의로 연결한다.
-   향후 프로젝트와 콘텐츠가 축적될 수 있는 기반을 마련한다.

## 2. Development Principles and Phases

### 2.1 Development principles

-   기존 Google AI Studio 프로젝트의 코드와 구조를 먼저 확인한다.
-   기존 GitHub 및 Vercel 연결을 유지하는 것을 우선한다.
-   기존 프로젝트를 임의로 삭제하거나 처음부터 새로 만들지 않는다.
-   PRD에 명시되지 않은 사항을 임의로 확정하지 않는다.
-   실제 백엔드가 없는 기능을 작동하는 것처럼 표현하지 않는다.
-   무료 또는 저비용 기술 구성을 우선 검토한다.
-   디자인과 콘텐츠를 분리해 향후 비개발자도 콘텐츠를 수정할 수 있도록
    설계한다.

### 2.2 Development phases

  Phase     Scope                          Goal
  --------- ------------------------------ -----------------------------
  Phase 1   전체 UI 및 시각적 프로토타입   페이지 구성과 디자인 확인
  Phase 2   실제 콘텐츠 및 이미지 반영     브랜드 홈페이지 완성도 향상
  Phase 3   관리자 페이지 및 데이터 관리   콘텐츠를 직접 등록·수정
  Phase 4   보안·백업·운영 환경            실제 서비스 공개 및 운영

### 2.3 Phase 1 scope

**포함** - HOME, ABOUT, PROJECTS, PROJECT DETAIL - JOURNAL, JOURNAL
DETAIL - CONTACT, PROJECT INQUIRY - 공통 Header 및 Footer - 메뉴 및
페이지 간 이동 - PC·태블릿·모바일 반응형 - 브랜드 방향에 맞는 임시
콘텐츠 및 이미지 - 기본 hover 및 페이지 전환 효과

**제외** - 실제 관리자 로그인 - 데이터베이스 연결 - 실제 문의 저장 및
이메일 발송 - 이미지 원본 저장소 - 자동 백업 및 복구 - 관리자 콘텐츠
편집 기능

Phase 1은 전체 화면과 사용자 경험을 확인하기 위한 프로토타입이다. 실제
동작하지 않는 기능은 작동하는 것처럼 표현하지 않는다.

## 4. Visual Design Direction

### 4.1 Overall concept

**Editorial Gallery + Natural & Sensory Design**

정돈된 에디토리얼 구조와 자연주의적이고 감각적인 분위기를 결합한다.

-   여백을 충분히 활용한다.
-   정돈된 그리드와 비대칭 갤러리 레이아웃을 사용한다.
-   실제 공간의 질감과 자연광이 드러나는 사진을 중심으로 구성한다.
-   기계적이거나 시공업체 같은 인상보다 따뜻하고 부드러운 스튜디오의
    분위기를 만든다.
-   전문성과 감각이 함께 드러나도록 한다.

### 4.2 Color palette

  Color         Hex       Usage
  ------------- --------- --------------------------
  Blue Gray     #86A2B1   보조 색상
  Off White     #F7F8F6   기본 배경
  Gray          #6B6665   본문 및 보조 텍스트
  Olive Green   #778732   포인트
  Dark Olive    #383515   강조 텍스트 및 일부 요소

크림색은 사용하지 않는다. 기본 배경은 Off White로 하고 Dark Olive, Blue
Gray, Olive Green을 보조적으로 활용한다.

### 4.3 Typography

-   단정하고 현대적인 산세리프 계열
-   약간 둥근 인상
-   지나치게 귀엽거나 장식적인 서체는 지양
-   필기체 사용 금지
-   제목과 본문 사이에 명확한 위계 설정

### 4.4 Logo and favicon

로고는 현재 제작 중이다.

프로토타입에서는 임시 워드마크 `unfold green`을 사용한다. - 소문자
표기 - Medium\~Semi Bold 정도의 무게 - 약간 둥근 산세리프 - `unfold`와
`green`은 블랙 또는 그린·그레이 계열로 표현

최종 로고 확정 후 Header, HOME, Footer, ABOUT 등에 반영한다.

파비콘은 최종 로고의 심볼을 활용한다. 작은 크기에서도 형태를 알아볼 수
있도록 단순화한다.

### 4.5 Motion

-   페이지 진입 시 Fade-in
-   이미지가 천천히 나타나는 효과
-   짧은 Slide + Fade
-   프로젝트 hover 시 제목 노출
-   부드러운 페이지 전환

과도한 패럴랙스나 장식적인 애니메이션은 지양한다. 모바일과 Reduced
Motion 환경을 고려한다.

### 4.6 Open Graph

-   HOME HERO 이미지를 기반으로 제작
-   권장 크기: 1200 × 630px
-   Title: `UNFOLD GREEN | Garden Design Studio`
-   Description: `Designing spaces through plants and nature.`
-   HERO 이미지 변경 시 OG 이미지도 함께 갱신할 수 있도록 한다.

### 7.2 Image protection

일반적인 무단 저장을 억제하는 수준의 보호 기능을 적용한다. - 이미지
우클릭 메뉴 비활성화 - 이미지 드래그 및 끌어다 저장 제한 - 원본 이미지의

공간에 보관 - 일반 텍스트 선택 및 복사는 제한하지 않는다. - 워터마크는
추후 검토한다.

**Technical limitation:** 웹 브라우저에 표시되는 이미지는 개발자 도구나
네트워크 요청 등을 통해 저장될 가능성이 있으므로 완전한 다운로드 방지는
불가능하다. 이미지 보호 기능은 무단 저장을 억제하는 수준으로 적용하며
방문자 경험을 과도하게 저해하지 않는다.

작업을 시작하기 전에 현재 프로젝트의 코드 구조와 구현 상태를 먼저
분석한다. 기존 프로젝트라면 임의로 삭제하거나 처음부터 다시 만들지 말고,
현재 구조와 GitHub 및 Vercel 연결을 최대한 유지하면서 개선한다.

HOME, ABOUT, PROJECTS, JOURNAL, CONTACT 전체 페이지와 각 상세 페이지
이동, 브랜드 디자인, 반응형 레이아웃을 구현한다. 실제 프로젝트 콘텐츠가
준비되지 않은 부분은 브랜드 방향에 맞는 임시 콘텐츠와 이미지로 구성한다.

로고는 제작 중이므로 임시 워드마크를 사용한다. 실제 관리자,
데이터베이스, 로그인, 문의 저장, 이메일 발송, 백업 기능은 1차 프로토타입
범위에 포함하지 않는다.

PRD의 요구사항을 임의로 생략하거나 변경하지 않는다. 구현이 어렵거나 추가
결정이 필요한 부분은 임의로 확정하지 말고 먼저 설명한다.

먼저 현재 프로젝트를 분석하고, 기존 구조 및 구현 상태와 권장 작업 계획을
간략히 제시한 뒤 프로토타입 구현을 진행한다.
